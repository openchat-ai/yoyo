### 10.5 Phase 4: Platform Abstraction (4a→4b→4c→4d)

Order matters: 4a (format) → 4b (libyoyo) → 4c (migrate `yoyo.ty`) → 4d (yoyo-asm).

#### Phase 4a: `.tyo` Format — **OPTIONAL**

Default = compile `.ty` directly to platform binary (Option A, no `.tyo` intermediate). 3-chain DDC uses Option A. Phase 4a is only relevant for incremental compilation / 3rd-party tool interop. `.tyo` magic = `b"TYO\x01"`; header 32 bytes LE; sections `.text` / `.data` / `.rela.text` / `.symtab` / `.strtab`. PLT32 = standard reloc type when `.ty` invokes `libyoyo_*`. Worked example for `30 50 00` → 32B header + 10B `.text` + 32B `.symtab`. **Full spec → `docs/aux/build.md` §".tyo format".**
