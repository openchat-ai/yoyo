# 01 — 愿景与非目标

## 愿景

YOYO 是一门 **可自举的独立小语言**：用自己的工具链把 `.ty`（及后续更高源语）变成可运行映像；在 Win32 应用面上能写真实程序；自举与分歧检测保证「编译器心」可测、可回归。

**成功（产品）**：外人按 `LANG-SURFACE` / ARCH 能写出并跑通程序，而不必先理解 Thompson 论文。  
**成功（地基）**：自举冷启与少宿主门禁保持绿；检测附录不退化。

## 版本角色

| 代 | 角色 |
|----|------|
| ≤1.0 | 自举 + 信任收口（地基，已毕业） |
| 1.1 | 独立语言第一成（表面 + 程序门禁，已毕业） |
| 1.2+ | 源语 / 库 / 网 / 跨平台（见 `YOYO-LANG-PLAN.md`） |
| 2.0 | 对外可称「一门小语言」的产品态（远景） |

## 非目标（OUT）

| OUT | 说明 |
|-----|------|
| 替代 C/Rust/Python 工业生态 | 不冲完整标准库与包管理宇宙 |
| Thompson-proof | 只做 detection + 缩根；#8 同仓共谋硬墙 |
| 空盘创世 | 禁止「零导入 / 无 bootstrap PE」幻想作交付 |
| Morph / MCU 主赛道 | 后端矩阵可存在，但非独立语言主尺 |
| 无界 tip 工厂 | 每版 ≤5 门，有 SCOPE |

## 双尺关系

```text
主尺：独立语言（写/编/跑/门禁）
附录：自举更硬、检测更实（回归）
```

附录变红 → 必须修；附录变绿但语言面没进步 → **不算**本阶段主进度。
